# Qeep brand

Qeep's logo is **Keyhole**: a bold Q whose bowl holds a keyhole. It says "a vault only you can open" and reads as
the letter Q at every size. The mark is one color, so it works on dark, on light and as a 16px favicon.

## Colors and type

| Token | Hex | Use |
| --- | --- | --- |
| Mint | `#3DDC97` | Mark, primary buttons, "protected" states |
| Ink | `#0D1117` | Backgrounds, mark on light |
| Paper | `#F3F4F1` | Light backgrounds |
| Text | `#F0F3F6` | Wordmark on dark |

Wordmark: **Sora ExtraBold (800)**, letter-spacing −4%. Body text: **Inter**.

## Rules

- Keep clear space around the mark of at least the width of the keyhole.
- Use the mark in one color only. Don't add gradients, outlines or shadows.
- Don't rotate the mark or move the tail.

The mark's source of truth in code is `apps/web/src/components/Brand.tsx`.
